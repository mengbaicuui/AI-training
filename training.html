选择 Loss 函数

大模型微调常用 Loss 函数

Loss 函数 适用任务 特点
Cross-Entropy Loss 文本生成、因果语言模型 最常用，计算 next-token 预测损失
Focal Loss 类别不平衡的分类任务 降低易分类样本权重，关注难样本
Label Smoothing CE 分类、生成 防止模型过度自信，提升泛化
Contrastive Loss 对比学习、Embedding 拉近正样本，推远负样本
💡
实践建议：对于大部分 SFT（Supervised Fine-Tuning）场景，标准的 Cross-Entropy Loss 即可满足需求。只有在遇到类别严重不平衡或特殊任务时，才需要考虑其他 Loss 函数。

Gradient Norm

常见学习率调度策略

  • Warmup：训练初期逐步提升学习率，避免初始梯度过大导致不稳定
  • Cosine Decay：学习率平滑下降，收敛更稳定，推荐使用
  • Linear Decay：简单直接，适合短期训练

常见问题排查

训练异常诊断表

现象 可能原因 解决方案
Loss = NaN / Inf 精度问题、学习率过大、数据异常 使用 float32、降低 LR、检查数据
Loss 剧烈震荡 学习率过大、Batch Size 太小 增加 Warmup、降低 LR、增大 Batch
Loss 下降极慢 学习率过小、Rank 太低 提高 LR、增大 Rank
Val Loss 先降后升 过拟合 早停、增加数据、加 Dropout
Train/Val Loss 都高 欠拟合、模型容量不足 增加 Rank、检查数据质量
🔥
重要提醒：待训练的参数一定要用 float32！如果使用 float16 可能会出现 NaN / Inf。基础模型可以用 FP16/BF16，但 LoRA 的 A、B 矩阵建议保持 FP32。
📏
Max Length 设置经验：统计训练数据的平均长度（去除异常值），然后设置 max_length = 平均长度 × 1.5。避免设置过大浪费显存，或过小截断重要信息。
