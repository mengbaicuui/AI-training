# 在 Llama Factory 里用 Cars_details_QA 做 SFT

## 1. 先跑预处理

在本项目根目录执行：

```bash
python data_preprocessing.py
```

会生成：

- `data/Cars_details_QA.json`：Alpaca 格式（instruction / input / output）
- `data/dataset_info.json`：Llama Factory 用的数据集描述

## 2. 在 Llama Factory Web UI 里怎么填

### 数据路径

填 **本项目 `data` 文件夹的绝对路径**：

```
/Users/mengbai/Documents/AI Training/knowledge-engineering/QA project/data
```

也就是说：**「数据路径」= 放 `Cars_details_QA.json` 和 `dataset_info.json` 的那个目录**，不要填到 `Cars_details_QA.json` 文件本身。

### 数据集

在「数据集」下拉里选：**`Cars_details_QA`**（和 `dataset_info.json` 里的名字一致）。

### 训练阶段

保持 **Supervised Fine-Tuning** 即可。

---

## 3. 如果你是在 Llama Factory 安装目录里跑

也可以把本项目的 `data` 接到 Llama Factory 的 `data` 里用：

1. 把 `QA project/data/Cars_details_QA.json` 复制到  
   `LLaMA-Factory/data/`
2. 在 `LLaMA-Factory/data/dataset_info.json` 里增加一条：

```json
"Cars_details_QA": {
  "file_name": "Cars_details_QA.json",
  "columns": {
    "prompt": "instruction",
    "query": "input",
    "response": "output"
  }
}
```

3. 在 Web UI 里：
   - **数据路径**：填 Llama Factory 的 data 目录（例如 `data` 或它的绝对路径）
   - **数据集**：选 **Cars_details_QA**

这样也可以正常用来做 SFT。
