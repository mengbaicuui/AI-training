# Graph RAG

定义：
利用知识图谱、实体关系图、图检索、图推理或 graph-based organization 提升检索与生成能力。

标签：
- graph rag

关注点：
- knowledge graph construction
- graph retrieval
- relation reasoning
- global/local retrieval
- graph-based summarization

## 小结
Graph RAG 的核心价值不只是“把知识变成图”，而是让系统具备更好的全局组织能力、关系推理能力与复杂问题分解能力。对长文档、叙事文本和多跳问题尤其重要。
