# Agentic RAG

定义：
通过 agent/planner/tool-use/self-reflection/workflow orchestration 等机制，动态控制检索、验证、规划与回答流程。

标签：
- agentic rag

可补充标签：
- corrective
- adaptive
- multimodal

关注点：
- planning
- iterative retrieval
- self-correction
- tool orchestration
- memory and workflow

2. Corrective Retrieval Augmented Generation (CRAG)

5. RA-ISF: Learning to Answer and Understand from Retrieval Augmented Feedback
6. MemoRAG: Moving towards Next-Gen RAG via Memory-Inspired Knowledge Discovery
7. Agentic Retrieval-Augmented Generation: A Survey on Agent-based RAG

## 小结
Agentic RAG 的重点是“流程控制权”从固定 pipeline 走向动态决策：什么时候检索、何时补检索、如何纠错、是否调用外部工具，都成为系统能力的一部分。
